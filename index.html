Sobre mim

Faço faculdade de Desenvolvimento de Sistemas para Internet (DSI) no Instituto Federal de Educação, Ciência e Tecnologia de Mato Grosso (IFMT) - Campus Octayde. Comecei a faculdade com o intuito de trabalhar e viver de programação.

Conheci a programação no começo da pandemia (2020) e desde então venho sonhando com a possibilidade de trabalhar na área, tentando aprender cada dia mais sobre esse universo.

Comecei com HTML, CSS e JavaScript no início de 2024. Desde então venho desenvolvendo projetos práticos com Python, Java e Dart, aplicando frameworks e ferramentas como Django, Flutter, Spring Boot e bancos de dados relacionais como PostgreSQL.
